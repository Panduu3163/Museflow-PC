# Shell artwork and sample metadata

The SVG covers and hero graphic in this directory are original procedural vector artwork authored for MuseFlow PC's shell preview, under the project's GPL-3.0 license. They do not reference external album art or Spotify assets.

Sample titles/artists in `src/catalog.rs` are fictional demonstration metadata. No associated audio is bundled or played. The 10,000-track set exists to exercise virtualization, filtering, stable identity and memory behavior.
