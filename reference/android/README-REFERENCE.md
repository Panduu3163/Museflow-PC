# Android reference only

This is a selected, non-buildable snapshot of MuseFlow's current on-disk source. It deliberately excludes Android build scripts, signing/configuration and UI implementations. Kotlin types, services and Android imports may reference files not copied; use them to understand behavior and platform boundaries, not as a standalone application.

For original project context see README.md, CHANGELOG.md and THIRD_PARTY_NOTICES.md in this directory. Those files are copied verbatim and contain Android-relative links and historical status; links outside the selection may not resolve here. Use the desktop root README for current workspace status.

For provenance and limitations see ../../docs/REFERENCE-GUIDE.md and ../../COPY-MANIFEST.json. Android build 66 glass is known buggy user-reported work, not an accepted desktop baseline.
